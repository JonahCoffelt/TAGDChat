A twitch style chat for in-person live events. Runs using a cloudflare tunnel for fast and secure local server hosting.

# Running 

Install dependencies:

```bash
npm install
```

Then run the server:

```bash
npm start
```

The host view will be at `http://127.0.0.1:3000/host.html`


# Chatters
Scan the QR code on the host page to join. Enter your name then enter chat messages.
